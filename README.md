# Драфт поручения

Статический сайт для подготовки текста поручения. Не требует сборки или сервера: откройте `index.html` в браузере.

## Возможности

- Sandbox, Skild AI, Titans и конвертация USD в RUB.
- Распознавание сумм в форматах `5к`, `5кк`, `5 млн`, `5 000 000`.
- Расчёт комиссии для поручений в рублях; долларовые заявки Sandbox и Skild AI считают целое количество бумаг по цене продукта.
- Дата поручения устанавливается автоматически. Срок покупки — через 60 календарных дней, срок конвертации — через 4 будних дня.
- Кнопка копирования готового текста.

## Публикация на GitHub Pages

Для публикации содержимое этой папки нужно разместить в корне отдельного GitHub-репозитория. Затем в настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/ (root)`. После сохранения GitHub покажет ссылку на сайт.

Перед публикацией проверьте видимость репозитория: в публичном репозитории код и шаблоны будут доступны всем.
